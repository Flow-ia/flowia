Agenda global

Toute action sensible demandera un PIN employé

Sidebar volontairement minimaliste en mode tablette : les 3 items sont les actions que n'importe quel employé peut faire sans s'identifier. Chaque action sensible (encaisser, modifier, annuler, crédit, promo) demande le PIN de l'employé. L'accès admin complet est possible via le bouton du bas avec le PIN admin.
Flux d'authentification
  1. Tablette au démarrage → sidebar neutre 3 items
  2. Clic "Encaisser" → modale "Qui encaisse ?" (liste employés avec can_encash)
  3. Choix employé → modale PIN employé 4 chiffres
  4. PIN valide → session JWT employee_pin_session 2h serveur / 5-15 min UI
  5. Timeout → retour automatique mode neutre
Tablette partagée
Mode pensé principalement pour tablette fixe au salon. Les employés naviguent sans se connecter, seules les actions sensibles demandent le PIN.
